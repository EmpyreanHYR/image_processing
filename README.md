# image_processing
# 多功能图像处理集成工具

## 功能
1. 注册账户与登录；
2. 读取单张图片或导入文件夹内所有图片进行图形处理；
3. 基本的图像处理操作，包括但不限于旋转、去噪、直方图均衡化、锐化、模糊、边缘检测、添加高斯噪点、调整亮度、滤镜、镜像翻转、颜色替换等功能；
4. 具有恢复原图，导出，撤销与反撤销等便捷操作按钮，

## 特别说明
